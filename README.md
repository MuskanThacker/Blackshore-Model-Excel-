# Blackshore-Model-Excel
Excel-based implementation of the Black–Scholes model for pricing European put option.

## Overview

This project implements the Black-Scholes Option Pricing Model in Microsoft Excel to calculate the theoretical prices of European put options.
The spreadsheet uses key financial variables such as:
* Stock Price (S)
* Strike Price (K)
* Risk-Free Interest Rate (r)
* Volatility (σ)
* Time to Maturity (T)

The model applies the Black-Scholes formula to estimate option values and helps in understanding the fundamentals of derivatives pricing and financial modeling.

## Features

* European Call Option Pricing
* European Put Option Pricing
* Excel-based financial modeling
* Formula-driven calculations
* User-friendly and editable structure
